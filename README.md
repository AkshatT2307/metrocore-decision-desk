# MetroCore Decision Desk — private organizer repository

Start with [KAGGLE_DEPLOYMENT.md](KAGGLE_DEPLOYMENT.md) for the complete teammate
handoff, outstanding tasks, validation commands, and Kaggle deployment procedure.

The current release is [releases/kaggle_v1](releases/kaggle_v1): five public
examples (two multimodal, three text), 240 disjoint hidden cases, a participant
starter notebook, and separate private scoring assets. The source-derived dataset
contains 245 cases, including 100 image conversions.

**Keep this repository private.** It contains hidden questions, reference answers,
and organizer review material. Only the release's `public/` contents, approved
starter, metric source, and finalized competition pages are for participant release.

Local release files are prepared. Kaggle hidden rerun enablement, hosted validation,
reference-label decisions, environment and event policy are still outstanding.
No competition has been deployed. The deployment guide lists the next actions.
